# 도화 (Dohwa)

독립적인 개인용 Discord 봇입니다. 기존 봇의 설정이나 기록을 복사하지 않습니다.

## 기본 기능

- `/핑`: 실행한 사람에게만 작동 여부와 응답 속도를 표시합니다.
- 실행할 때 슬래시 명령어를 등록합니다.
- 토큰 누락 또는 로그인 실패 시 안내를 표시합니다.

## 설정

`.env.example`을 `.env`로 복사하고 `DISCORD_TOKEN=` 뒤에 도화봇 토큰을 입력하세요.
이미 `.env`가 있다면 해당 파일을 사용하세요. 토큰과 DB는 GitHub에 올리지 않습니다.
호스팅에서는 환경 변수 `DISCORD_TOKEN`을 직접 등록할 수도 있습니다. 환경 변수가 `.env`보다 우선합니다.

## 명령어와 버튼 권한

디스코드 역할은 `/역할부여`로 이 서버의 카테고리에 연결합니다. 이미 연결된 역할은 바로 사용합니다.
권한을 확인할 때는 보유한 역할을 모두 확인합니다.

| 사용자 | 권한 |
| --- | --- |
| 서버장, 도화 소유자 | 모든 도화 명령어와 외활 요청방 버튼 |
| 총관리자 | 일반 명령어, `/외활권 부여`, `/외활권 회수`, 외활 요청방 버튼 |
| 단속팀 | 일반 명령어와 외활 요청방 버튼 |
| 일반 유저 | `/정보`, `/외활요청` |

서버장과 도화 소유자는 서버원별 시간을 조정할 수 있습니다.

- `/외활시간추가감소 유저:@유저 시간:2`는 외활 가능 시간에 2시간을 추가합니다.
- `/활동시간추가감소 유저:@유저 시간:-2`는 기록된 활동시간에서 2시간을 차감하고 그에 따른 외활 가능 시간도 갱신합니다.
- 두 명령 모두 시간 단위의 양수 또는 음수 정수를 받습니다. 0시간과 현재 잔액을 초과하는 감소 요청은 거절합니다.

## 활동시간 자동 저장

`/정보 [유저]` 카드에서 활동시간을 조회합니다. 음성방에 들어온 일반 유저를 서버 ID·유저 ID별로 집계합니다.

- 본인 포함 봇이 아닌 2명 이상, 마이크와 헤드셋이 켜져 있으면 활동입니다. 서버 음소거·서버 헤드셋 차단·스테이지 청중·AFK방은 음성 활동으로 인정하지 않습니다.
- 같은 서버에서 본인이 메시지를 보내면 혼자 있거나 음소거/헤드셋 차단 중이어도 활동이 재개됩니다. 음성방 밖의 채팅은 이번 집계에 포함하지 않습니다.
- 음성 활동이 없으면 시간을 보류합니다. 30분 미만에 채팅 또는 음성 활동이 재개되면 보류 시간을 포함하고, 정확히 30분 이상이면 그 구간 전체를 버립니다. 이후 재개 시점부터 다시 누적합니다.
- 음성방 퇴장 시 30분 미만의 보류 구간은 포함합니다. 봇 재시작·연결 끊김 시 미확정 보류 구간은 버리며, 오프라인 시간은 적립하지 않습니다.
- 채팅 내용이나 녹음은 저장하지 않습니다. 봇이 볼 수 있는 채널의 새 메시지만 감지합니다.
- 기본 DB: bot.py 옆 activity.sqlite3. ACTIVITY_DATABASE_PATH로 영구 저장 경로를 지정할 수 있습니다. 호스팅 업데이트/재설치 때 이 DB를 보존해야 합니다.
- SQLite activity_totals(guild_id, user_id, active_seconds)에 확정 시간을 저장하며 약 10초마다 갱신합니다. 추후 기능은 ActivityStore.total(guild_id, user_id)로 조회할 수 있습니다. 보류 시간은 조회값에 포함되지 않습니다.
- 기본 Gateway intents만 사용합니다. 채팅 내용이 필요하지 않으므로 Message Content Intent는 필요하지 않습니다.
- 한 토큰으로 프로세스 하나만 실행하세요. 갑작스러운 종료 시 마지막 저장 이후의 짧은 구간은 유실될 수 있습니다.

검증: python -m unittest discover -s . -p test_activity.py -v

## 외활 요청

- 서버장 또는 도화 소유자가 먼저 `/외활요청방 채널:#외활요청`으로 요청방을 지정합니다.
- 일반 유저는 `/외활요청 외활시간:2`로 외활 2시간을 신청할 수 있습니다.
- 활동시간 5시간당 외활 1시간을 얻습니다. 이미 승인된 외활 시간은 사용량으로 차감합니다. 활동시간 원본은 줄이지 않습니다.
- 잔액 부족은 빨간 비공개 임베드로 자동 거절합니다. 미입력/미기록 유저의 잔액은 0시간입니다.
- 노란 요청 임베드에 유저 멘션, 외활 요청시간, 요청 당시 활동시간을 표시합니다.
- 수락·거절·부르기 버튼은 서버장, 총관리자, 단속팀, 도화 소유자가 사용할 수 있습니다.
- 승인 시 초록색, 거절 시 빨간색으로 요청 임베드를 갱신합니다. 승인은 잔액을 재검증하며 중복 승인은 차감되지 않습니다.
- 승인 시각부터 만료 시각을 계산하고, 대상 멘션과 함께 '외활이 허락되었습니다! 지금부터 시간이 지나갑니다.'를 DM으로 보냅니다.
- 종료 시 대상 멘션과 함께 '외활이 끝났습니다! 다시 서버로 돌아오세요!' DM을 보내고, 요청방에 빨간 종료 임베드를 별도로 게시합니다. 부르기는 같은 DM을 재전송합니다(1분 간격).
- 종료 검사는 30초 간격입니다. 봇이 꺼진 동안에도 종료 시각은 지나가며, 다시 시작하면 밀린 종료 알림을 처리합니다.
- DM이 차단되면 실패를 표시하지만 승인·시간 차감·카운트다운은 유지합니다. 요청방 알림은 DM 차단과 무관하게 처리합니다.
- 일시적인 API 전송 실패는 재시도합니다. Discord 전송 직후 DB 저장 전에 프로세스가 강제 종료되는 극히 짧은 구간에서는 알림이 중복될 수 있습니다.
- DB는 기존 activity.sqlite3를 함께 사용합니다. DB를 삭제하지 마세요. 같은 DB로 여러 봇 프로세스를 동시에 실행하지 마세요.
- 정보 카드에 외활권 보유 여부와 잔여 시간을 표시합니다. 외활요청 자격은 활동시간 잔액 기준이며 외활권 보유를 추가 제한 조건으로 사용하지 않습니다.

검증: `python -m unittest discover -s . -p "test_*.py" -v`

## 유저 정보 카드

- `/정보`: 명령어 사용자의 정보 이미지를 표시합니다.
- `/정보 유저:@유저`: 선택한 서버원의 정보 이미지를 표시합니다. 정보 조회는 일반 유저도 가능합니다.
- 서버장 또는 도화 소유자는 `/역할부여 카테고리:서버장 역할:@역할`로 기존 Discord 역할을 카드 분류와 도화 권한에 연결합니다.
- 여러 연결 역할을 보유했다면 카드는 Discord 역할 순서에서 가장 높은 역할을 표시합니다. 지정 역할이 없으면 서버원입니다.
- `/외활권 부여 유저:@유저`, `/외활권 회수 유저:@유저`: 서버장, 총관리자, 도화 소유자가 외활권 보유 여부를 설정합니다. 없거나 미입력이면 빨간색, 보유면 초록색 막대입니다.
- 서버장 파랑, 총관리자 검정, 단속팀 빨강, 홍보팀 보라, 활동팀 노랑, 뉴관팀 연두, 서버원 하늘색입니다. 팀장은 해당 팀의 어두운 색상을 사용합니다.
- 가로 1500 × 세로 900 이미지에 정사각형 프로필, 작은 닉네임, 활동시간, 외활 잔여시간, 직책, 외활권 막대, 서버 이름을 표시합니다.
- 시간은 정수 시간만 표시합니다. 기록이 없으면 0시간, 분·초는 표시하지 않지만 원본 활동 기록은 보존합니다. 외활 잔여시간은 승인된 사용량을 차감한 값입니다.
- 서버 프로필 사진을 우선 사용하며, 기본 아바타도 지원합니다. 중앙 기준 정사각형으로 자르고 종횡비를 늘이지 않습니다.
- 채팅방에서 봇의 파일 첨부 권한이 필요합니다. 새 requirements.txt로 Pillow를 설치해야 합니다.
- assets 폴더의 배경·한글 글꼴을 함께 배포해야 합니다. 글꼴 Nanum Gothic은 동봉한 OFL.txt 라이선스로 배포합니다.
- DB는 기존 activity.sqlite3를 사용합니다. profile_roles / external_permits 테이블에 설정을 저장합니다.
